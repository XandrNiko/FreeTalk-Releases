# FreeTalk downloads

Windows distributions and installation information for FreeTalk.

## Install

Open [Releases](https://github.com/XandrNiko/FreeTalk-Releases/releases), choose
the version you want to test and download its Windows x64 installer. Run the
installer, then open FreeTalk from the Start menu.

Prereleases are test versions. Read their known limitations before installing.
Only download assets attached to an official release on this repository.

## Connect

Ask the person operating your FreeTalk server for a personal connection file.
Import it in FreeTalk. Connection files are private invitations: do not post
them in public issues, screenshots or this repository.

The server is distributed separately from the client. You do not need to run
a server to use a friend's server.

## Updates and verification

The client verifies signed update metadata and package integrity before
installation. A download page does not replace those checks. Release assets
include checksums and the applicable license and third-party notices.

## Repository contents

This repository contains public distribution documentation and release assets.
Application source code and development history are maintained separately.
GitHub's automatically generated source archives contain only this public
documentation repository; they are not client installers.

Never share passwords, private signing keys, server configuration, connection
files or personal logs in public reports.
